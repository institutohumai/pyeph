2""" 

3Puente de comparabilidad para las bases de la EPH posteriores al rediseño 

42024. 

5 

6A partir del cuarto trimestre de 2024, el rediseño del cuestionario de la 

7EPH eliminó de las bases usuarias varias variables agregadas y publicó en su 

8lugar sub-componentes por fuente. Este módulo reconstruye las variables 

9eliminadas con reglas determinísticas, para mantener la comparabilidad con 

10la serie histórica. 

11 

12Referencias 

13----------- 

14- Tessmer, G. y Boggiano, B. (2026). "From Breaks to Bridges: Harmonizing 

15 the New and Old Permanent Household Survey for Consistent Labor Market 

16 Series". SSRN Working Paper 6597399. 

17- Observatorio Económico Social UNR. "Manual Metodológico EPH – 

18 Observatorio", Parte A. https://hdl.handle.net/2133/33253 

19 (datasets: https://doi.org/10.57715/UNR/BL85Z8). 

20- Implementación de referencia en R propuesta al paquete `eph` de rOpenSci: 

21 https://github.com/ropensci/eph/issues/70 

22"""

60def comparability_bridge(base, base_hogar=None): 

61 """ 

62 Reconstruye las variables agregadas eliminadas por el rediseño 2024. 

63 

64 En la base hogar reconstruye las estrategias del hogar (V5, V11, V21 y 

65 V22) a partir de sus sub-componentes. En la base individual corrige la 

66 inversión PP11L1/PP11L2 (si detecta la condición de error) y reconstruye 

67 los montos de ingresos no laborales (V2_M, V5_M, V11_M, V21_M y V22_M) 

68 usando como control la variable de estrategia correspondiente de la base 

69 hogar, apareada por CODUSU + NRO_HOGAR. 

70 

71 Las bases anteriores a 2024 T4 no requieren puente y se devuelven sin 

72 cambios. Si una variable agregada ya existe, o faltan sus 

73 sub-componentes, su reconstrucción se omite con un aviso. Las variables 

74 reconstruidas se agregan al final; ningún valor existente se modifica 

75 (única excepción: el intercambio PP11L1/PP11L2 cuando corresponde). 

76 

77 Parameters 

78 ---------- 

79 base : pandas.DataFrame 

80 Base usuaria de la EPH (hogar o individual), tal como la devuelve 

81 ``pyeph.get(data="eph", ...)``. El tipo se detecta por la presencia 

82 de la columna COMPONENTE. 

83 base_hogar : pandas.DataFrame, optional 

84 Base hogar del mismo trimestre. Obligatoria cuando ``base`` es una 

85 base individual (aporta las variables control; si sus agregados 

86 faltan, se reconstruyen internamente). Se ignora cuando ``base`` ya 

87 es una base de hogar. 

88 

89 Returns 

90 ------- 

91 pandas.DataFrame 

92 Copia de ``base`` con las variables reconstruidas agregadas. 

93 

94 Examples 

95 -------- 

96 >>> hogares = pyeph.get(data="eph", year=2025, period=1, base_type="hogar") 

97 >>> individuos = pyeph.get(data="eph", year=2025, period=1, base_type="individual") 

98 >>> hogares = comparability_bridge(hogares) 

99 >>> individuos = comparability_bridge(individuos, base_hogar=hogares) 

100 """ 

101 if not isinstance(base, pd.DataFrame): 

102 raise ValueError("base debe ser un pandas.DataFrame (base usuaria de hogar o individual)") 

103 

104 faltan = [c for c in ('ANO4', 'TRIMESTRE') if c not in base.columns] 

105 if faltan: 

106 raise ValueError( 

107 f"La base no contiene la(s) columna(s) {faltan}, necesarias para determinar el periodo" 

108 ) 

109 

110 # El puente aplica solo a las bases de la nueva metodologia (>= 2024 T4) 

111 if _era(base) == 'legacy': 

112 logger.info( 

113 "Base anterior al cambio metodologico (2024 T4): no requiere puente. " 

114 "Se devuelve sin cambios." 

115 ) 

116 return base.copy() 

117 

118 es_individual = 'COMPONENTE' in base.columns 

119 

120 # ---- Base HOGAR --------------------------------------------------------- 

121 if not es_individual: 

122 if base_hogar is not None: 

123 logger.warning("base_hogar se ignora: base ya es una base de hogar.") 

124 return _puente_hogar(base.copy()) 

125 

126 # ---- Base INDIVIDUAL ---------------------------------------------------- 

127 if base_hogar is None: 

128 raise ValueError( 

129 "Para una base individual se requiere base_hogar (la base hogar del " 

130 "mismo trimestre): las variables control de la reconstruccion " 

131 "(V2, V5, V11, V21, V22) provienen de la base de hogar" 

132 ) 

133 if not isinstance(base_hogar, pd.DataFrame) or 'COMPONENTE' in base_hogar.columns: 

134 raise ValueError( 

135 "base_hogar no parece una base de hogar: debe ser un pandas.DataFrame " 

136 "sin la columna COMPONENTE" 

137 ) 

138 per_indiv = _periodos(base) 

139 per_hogar = _periodos(base_hogar) 

140 if per_indiv != per_hogar: 

141 raise ValueError( 

142 f"base ({per_indiv}) y base_hogar ({per_hogar}) no pertenecen al mismo periodo" 

143 ) 

144 

145 df = base.copy() 

146 

147 # Correccion PP11L1/PP11L2: en las bases publicadas los contenidos de 

148 # ambas columnas aparecen intercambiados. Condicion de error: PP11L2 

149 # registra los niveles 1/2/3 (que corresponden a la PP11L1 del 

150 # cuestionario legacy) y PP11L1 nunca registra el nivel 3. 

151 if {'PP11L1', 'PP11L2'}.issubset(df.columns): 

152 pp11l1 = pd.to_numeric(df['PP11L1'], errors='coerce') 

153 pp11l2 = pd.to_numeric(df['PP11L2'], errors='coerce') 

154 if {1, 2, 3}.issubset(set(pp11l2.dropna().unique())) and 3 not in set(pp11l1.dropna().unique()): 

155 logger.info("Se detecto la inversion PP11L1/PP11L2: se intercambian ambas columnas.") 

156 df[['PP11L1', 'PP11L2']] = df[['PP11L2', 'PP11L1']].to_numpy() 

157 

158 # Variables control: si a la base hogar le faltan los agregados, se 

159 # reconstruyen aca (solo para uso interno; base_hogar no se devuelve). 

160 hogar = _puente_hogar(base_hogar.copy(), avisar=False) 

161 

162 if hogar.duplicated(subset=['CODUSU', 'NRO_HOGAR']).any(): 

163 raise ValueError( 

164 "base_hogar tiene combinaciones CODUSU + NRO_HOGAR duplicadas: " 

165 "no es posible asignar los controles del hogar" 

166 ) 

167 

168 creadas = [] 

169 for dependiente, independientes in RELACIONES_INDIVIDUAL.items(): 

170 control_var = CONTROLES[dependiente] 

171 if ( 

172 dependiente not in df.columns 

173 and all(c in df.columns for c in independientes) 

174 and control_var in hogar.columns 

175 ): 

176 m = df[independientes].apply(pd.to_numeric, errors='coerce').to_numpy(dtype=float) 

177 ctrl = _control_del_hogar(df, hogar, control_var) 

178 df[dependiente] = [ 

179 _reconstruye_ingreso(m[i, :], ctrl[i]) for i in range(len(df)) 

180 ] 

181 creadas.append(dependiente) 

182 else: 

183 logger.info( 

184 "Se omite '%s': ya existe, faltan sus variables de origen o falta " 

185 "la variable control %s en base_hogar.", dependiente, control_var 

186 ) 

187 if creadas: 

188 logger.info("Variables reconstruidas en la base individual: %s", ", ".join(creadas)) 

189 

190 return df

197def _puente_hogar(df, avisar=True): 

198 """Reconstruye los agregados sí/no de una base hogar.""" 

199 creadas = [] 

200 for dependiente, independientes in RELACIONES_HOGAR.items(): 

201 if dependiente not in df.columns and all(c in df.columns for c in independientes): 

202 m = df[independientes].apply(pd.to_numeric, errors='coerce').to_numpy(dtype=float) 

203 valores = [_calcula_dependiente(m[i, :]) for i in range(len(df))] 

204 df[dependiente] = pd.array(valores, dtype='Int64') 

205 creadas.append(dependiente) 

206 elif avisar: 

207 logger.info( 

208 "Se omite '%s': ya existe o faltan sus variables de origen.", dependiente 

209 ) 

210 if avisar and creadas: 

211 logger.info("Variables reconstruidas en la base de hogar: %s", ", ".join(creadas)) 

212 return df

215def _calcula_dependiente(valores): 

216 """ 

217 Agregado sí/no a partir de los sub-componentes de una fila. 

218 Códigos: 1 = Sí, 2 = No, 0 = No corresponde, 9 = Ns/Nr. 

219 Lógica idéntica al pipeline EPH-Observatorio (02.check.R, sección 3.1). 

220 """ 

221 valores = np.asarray(valores, dtype=float) 

222 

223 # 2 sub-componentes: regla de dominancia transitiva 1 > 2 > 0 > 9 

224 if len(valores) == 2: 

225 # Valores fuera de {1, 2, 0, 9} (o faltantes) -> sin dato, como en la 

226 # implementacion de referencia en R. 

227 if not np.isin(valores, (1.0, 2.0, 0.0, 9.0)).all(): 

228 return None 

229 for nivel in (1, 2, 0, 9): 

230 if nivel in valores: 

231 return nivel 

232 return None # pragma: no cover 

233 

234 # 3 sub-componentes: reglas especiales sobre la dominancia estricta 

235 if len(valores) == 3: 

236 # Prioridad 1: al menos un 1 (Si) -> 1 

237 if (valores == 1).any(): 

238 return 1 

239 # Prioridad 2: solo hay 0 (No corresponde) y 9 (Ns/Nr) 

240 if np.isin(valores, (0.0, 9.0)).all(): 

241 # dos o mas 9 -> 9; un solo 9 (o ninguno) -> 0 

242 return 9 if (valores == 9).sum() >= 2 else 0 

243 # Prioridad 3 (default): 2 (No) 

244 return 2 

245 

246 raise ValueError("La reconstruccion solo esta definida para 2 o 3 sub-componentes")

249def _reconstruye_ingreso(valores, valor_control): 

250 """ 

251 Monto agregado a partir de los sub-componentes de una fila y el valor de 

252 la variable control del hogar. Códigos negativos de INDEC: -7 = no 

253 corresponde, -8 = no tuvo ingresos ese mes, -9 = Ns/Nr. 

254 Lógica idéntica al pipeline EPH-Observatorio (02.check.R, sección 3.2). 

255 """ 

256 valores = np.asarray(valores, dtype=float) 

257 validos = valores[~np.isnan(valores)] 

258 

259 # Prioridad absoluta: hay ingresos positivos -> suma de los no negativos 

260 if (validos > 0).any(): 

261 return float(validos[validos >= 0].sum()) 

262 # Prioridad 1: todos los sub-componentes en 0 -> 0 

263 if (validos == 0).all(): 

264 return 0.0 

265 # Prioridad 2: el hogar contesto [2 = No] a la fuente correspondiente -> -7 

266 if not np.isnan(valor_control) and valor_control == 2: 

267 return -7.0 

268 # Prioridad 3: incertidumbre; algun -9 -> el total no puede determinarse 

269 if (validos == -9).any(): 

270 return -9.0 

271 # Prioridad 4: ingreso potencial; sin -9 pero con algun -8 -> -8 

272 if (validos == -8).any(): 

273 return -8.0 

274 # Prioridad 5: no aplicabilidad; solo quedan -7 -> -7 

275 if (validos == -7).all(): 

276 return -7.0 

277 # Prioridad 6 (default): cero explicito 

278 return 0.0

281def _control_del_hogar(df, hogar, control_var): 

282 """ 

283 Devuelve, para cada fila de la base individual, el valor de la variable 

284 control de su hogar (apareo por CODUSU + NRO_HOGAR; NaN si el individuo 

285 no tiene hogar en la base de hogar). 

286 """ 

287 apareo = df[['CODUSU', 'NRO_HOGAR']].merge( 

288 hogar[['CODUSU', 'NRO_HOGAR', control_var]], 

289 on=['CODUSU', 'NRO_HOGAR'], 

290 how='left', 

291 ) 

292 sin_hogar = int(apareo[control_var].isna().sum()) 

293 ctrl = pd.to_numeric(apareo[control_var], errors='coerce').to_numpy(dtype=float) 

294 if sin_hogar and np.isnan(ctrl).sum() == sin_hogar: 

295 logger.info( 

296 "%d individuo(s) sin hogar correspondiente en base_hogar: su control queda NaN.", 

297 sin_hogar, 

298 ) 

299 return ctrl

302def _era(base): 

303 """ 

304 Clasifica la base en 'legacy' (< 2024 T4) o 'nueva' (>= 2024 T4). 

305 Lanza ValueError si la base mezcla períodos de ambas metodologías. 

306 """ 

307 anio = pd.to_numeric(base['ANO4'], errors='coerce') 

308 trim = pd.to_numeric(base['TRIMESTRE'], errors='coerce') 

309 periodos = (anio * 100 + trim).dropna().unique() 

310 if len(periodos) == 0: 

311 raise ValueError("No se pudo determinar el periodo: ANO4/TRIMESTRE sin datos validos") 

312 nueva = periodos >= _PERIODO_NUEVA 

313 if nueva.all(): 

314 return 'nueva' 

315 if not nueva.any(): 

316 return 'legacy' 

317 raise ValueError( 

318 "La base combina periodos anteriores y posteriores al cambio metodologico " 

319 "(2024 T4). Separe los periodos y aplique la funcion solo a los trimestres " 

320 "de la nueva metodologia" 

321 ) 

322

324def _periodos(base): 

325 """Etiquetas de período de una base, ordenadas (p. ej. '2025-T1').""" 

326 anio = pd.to_numeric(base['ANO4'], errors='coerce') 

327 trim = pd.to_numeric(base['TRIMESTRE'], errors='coerce') 

328 etiquetas = sorted( 

329 f"{int(a)}-T{int(t)}" for a, t in set(zip(anio, trim)) 

330 if not (np.isnan(a) or np.isnan(t)) 

331 ) 

332 return ", ".join(etiquetas)
